# AI Doctor Image Classification

## Combined Dataset
https://www.kaggle.com/datasets/mattmcauley/ai-doctor-image-classification

## Citations

### Bone Fracture Dataset
Vuppala, A. S. (2021). *Bone Fracture Detection using X-Rays* [Data set]. Kaggle. https://www.kaggle.com/datasets/vuppalaadithyasairam/bone-fracture-detection-using-xrays

### Chest X-Ray Dataset
Kermany, D., Zhang, K., & Goldbaum, M. (2018). *Large Dataset of Labeled Optical Coherence Tomography (OCT) and Chest X-Ray Images* (V3) [Data set]. Mendeley Data. https://doi.org/10.17632/rscbjbr9sj.3

### Brain Tumor Dataset
Bhuvaji, S., Kadam, A., Bhumkar, P., Dedge, S., & Kanchan, S. (2020). *Brain Tumor Classification (MRI)* [Data set]. Kaggle. https://doi.org/10.34740/KAGGLE/DSV/12745533

### Blood Cancer Dataset
Eshraghi, R., & Ghaderzadeh, M. (2023). *Blood Cell Cancer (ALL - 4 class)* [Data set]. Kaggle. https://www.kaggle.com/datasets/mohammadamireshraghi/blood-cell-cancer-all-4class

### Breast Cancer Dataset
Mooney, P. (2018). *Breast Histopathology Images* [Data set]. Kaggle. https://www.kaggle.com/datasets/paultimothymooney/breast-histopathology-images

*Note: This dataset is derived from a larger dataset created for the following publication:*
Janowczyk, A., & Madabhushi, A. (2016). Deep learning for digital pathology image analysis: A comprehensive tutorial with selected use cases. *Journal of Pathology Informatics*, *7*, 29. https://doi.org/10.4103/2153-3539.186902
